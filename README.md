# TempThreads

A weather-aware outfit assistant. Swipe to teach it your style, check in on how outfits felt, and it learns whether you run cold or warm.

- Live weather: [Open-Meteo](https://open-meteo.com/) (free for non-commercial use)
- Maps: Google Maps links and embed
- Hotels: OpenStreetMap via the Overpass API

Static site: open `index.html` through any web server, e.g. `python3 -m http.server`.
Profiles and learning are stored in the browser's localStorage only.
